About BBIDS

Behavior-Based Intrusion Detection System

BBIDS is an intelligent security solution that uses Machine Learning to detect anomalies in user behavior.

Key Features:

  • Real-time anomaly detection using Isolation Forest algorithm
  • Behavior analysis based on login patterns, CPU usage, file access, and network activity
  • MITM (Man-in-the-Middle) attack monitoring
  • Interactive dashboard with visual analytics

Technologies Used:

  • Frontend: HTML, CSS, JavaScript
  • Backend: Node.js, Express
  • Machine Learning: Python, Scikit-learn (Isolation Forest)
  • Network Monitoring: mitmproxy
